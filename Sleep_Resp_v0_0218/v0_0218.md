*Hardware
ESP32-A (Chest)(Master)
·ESP32-S3
·MPU6050 Acceleration sensor (SDA→GPIO8, SCL→GPIO9)

ESP32-B (Head)
·ESP32-S3
·MAX30102 Heart Rate and Blood Oxygen Sensor (SDA→GPIO8, SCL→GPIO9)


*Implemented functions 
Heart Rate & Blood Oxygen (MAX30102) 
·Real-time Heart Rate detection (BPM 
·Blood oxygen saturation test (SpO2% 
·Non-wearing detection (automatically ignored if the IR value is below the threshold) 
·Four times the average smoothed blood oxygen values 
 
Chest breathing (MPU6050 )
·Kalman filter denoising 
·FFT spectrum analysis calculates respiratory rate (RR, updated every 5 seconds) 
·Respiratory amplitude measurement (Amp, 5-time mean smooth) 
·Flipping detection (when the Angle change is greater than 30 degrees, pause for 4 seconds for data collection) 
 
BLE communication 
·ESP32-B serves as an accessory to broadcast HR and SpO2 
·The ESP32-A serves as the main control, while simultaneously connecting the ESP32-B and the mobile phone 
·The main control unit summarizes all the data and sends it to the mobile phone every 5 seconds 
 
iOS App (SwiftUI )
·Page 1: Scan to connect Bluetooth devices 
·Page Two: Hello Homepage 
·Page 3: Display four data cards (HR, SpO2, RR, Amp) 
·Breathing animation circle (speed controlled by RR, size controlled by Amp)
